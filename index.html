什么是 Vibe Coding？

用日常的话告诉 AI 你要什么，由 AI 写出代码；你负责看结果、提意见，直到做对为止。

就像你对室内设计师说“我要一个明亮的办公室，要有会议区”，设计师画图，你看了再说哪里要改。差别只是，这次画出来的是能用的软件。

  1. 说用中文描述你要的功能，例如“做一个请假申请表”。
  2. 看Claude Code 做出来，你打开试用、检查。
  3. 改哪里不对就直接说，AI 修改，再试，直到满意。

一天 5 大主题，从数据、网站到上线。

一天课程分成 5 大主题。我们不是只教你做几个固定的系统，而是教你建立系统的架构、方法、格式和安全性。学会这些，你就能做自己想做的系统。

架构

一个系统由哪些部分组成，怎么拆、怎么连。

方法

怎么向 AI 说清楚需求，怎么检查结果、修正。

格式

页面、数据和报表怎么整理，才好用、好维护。

安全性

哪些资料不能放、权限怎么设、上线前要查什么。

课堂上会教到

  • Google Sheet / Excel
  • Dashboard
  • 预约 + WhatsApp 网站
  • OCR 手机扫描
  • Skill
  • MCP
  1. 1

    连接 Google Sheet / Excel，做出清清楚楚的 Dashboard

    你会学到：把 Google Sheet 或 Excel 的数据连接起来，做成 Dashboard。数据再多，也能整理得一目了然，管理层打开就看懂。

  2. 2

    做专业、吸引眼球的企业网站

    你会学到：跳出传统网站的样子，做一个让人愿意停下来看的网站，并加上预约功能、WhatsApp 按钮和索取客户资料的表单，访客一进来就能联络你。

  3. 3

    OCR 扫描：用手机做 Web App 系统

    你会学到：用手机拍照，把图片里的文字自动记录下来，存进 Google Sheet 或 Web App。例如开销记录（Expenses Tracking）、库存（Inventory）、浪费记录（Waste Tracking）系统，告别重复 key in。

  4. 4

    系统创建流程：为企业和各部门设计系统

    你会学到：怎样设计适合自己公司或部门的系统来提升绩效：系统搭建的架构、安全措施，以及如何部署到线上，让同事真正用起来。

  5. 5

    安装 Skills 和 MCP，并明白它们为什么重要

    你会学到：什么是 Skill、什么是 MCP，怎样安装和使用，以及为什么它们能让 AI 更懂你的工作、连接你的数据和工具。

报名之前，你可能有这些担心。

我们先老实回答。如果你的情况不在这里，欢迎直接问。

“我完全没有编程基础，会不会跟不上？”

课程从装好工具开始，每一步都带着做。你需要的是把事情讲清楚的能力，不是 IT 背景。

“AI 写错了怎么办？系统出事谁负责？”

AI 确实会出错，所以课程会教你怎么测试、检查和修正，并讲解系统搭建的安全措施，也会知道哪些环节不能全交给 AI。

“公司的资料会不会外泄？”

练习一律用模拟数据。我们也会讲清楚，哪些资料不该直接丢给任何 AI 工具，以及上线前要检查什么。

“学完是不是只是做个样子，用不上？”

课堂教的是建立系统的架构、方法、格式和安全性，不是照着练习题抄。学会之后，你做的是自己公司真正需要的系统。

“工作很忙，没时间学那么多。”

只需要一个周末的一天（10AM–6PM）。小班制 12 人，老师在旁边带着做，卡住了当场解决。

“学了 AI 工具，是不是很快就过时？”

工具会变，但“把需求说清楚、检查结果、修正”的方法不会，换工具也用得上。课后还有 WhatsApp 群，老师会定期更新 AI 资讯和方法，你不会落后。

常见问题

课程要上多久？一天怎么安排？

公开班是一天课程，周末上午 10 点到下午 6 点。一天里走完 5 大主题：Dashboard、专业网站、OCR 手机扫描、系统创建流程，以及 Skills 和 MCP，学会设计、搭建和上线一个系统的方法。小班制，每班 12 人，老师在旁边带着做。

一天能学会做多少个系统？

课程不追求一天做完多少个系统。重点是学会建立系统的架构、方法、格式和安全性，Skill、MCP、Dashboard、Landing Page 和 OCR 都会教到。学会这些方法，你就能做自己想做的系统，而不是只会照着做几个固定的。

上完课还有支援吗？

有。学员会加入 WhatsApp 群，老师会在群里定期更新 AI 资讯和方法，也可以继续交流使用上遇到的问题。

上完课有证书吗？

没有证书。这门课的重点是动手做，你带走的是做系统的方法和自己做出来的作品，而不是一张证书。

我从来没写过代码，真的可以吗？

可以。这门课就是为没有编程基础的人设计的，从安装和认识界面开始，不假设你懂任何术语。遇到不懂的词，我们会用办公室里的例子解释。

指令一定要用英文吗？

不用。Claude 可以理解中文指令，你用平时说话的方式描述需求就行。课程里也会教你怎样把中文需求写得更清楚、更不容易被误解。

上课前要准备什么？

自备一台能上网的笔记本电脑（Windows 或 Mac），以及一个 Claude 账号。上课时会带你一步步完成环境设置，不用事先装任何东西。

Claude Code 要另外付费吗？

使用 Claude Code 需要符合官方要求的 Claude 付费方案。方案与价格由 Anthropic 决定且可能调整，请以官方页面为准。我们会在报名前告诉你需要准备哪一类账号。

做出来的系统，真的能放在公司使用吗？

适合：内部小工具、请假和客户跟进系统、OCR 整理、报表和 Dashboard、公司网站与活动页。

不适合：牵涉大量交易的核心会计系统，或需要严格合规认证的系统，这类仍应找专业团队。课程会教你判断这条界线在哪里。

输入公司资料给 AI，安全吗？

课程练习使用模拟数据，不需要你提供真实客户或员工资料。同时会讲解：哪些资料不应该放进 AI 工具，以及系统上线前要做哪些基本的安全检查。

AI 写出来的东西有错，我看不懂代码怎么办？

你不需要读懂每一行代码。课程会教你用“实际操作测试”的方式检查：用几组正常和不正常的数据去试，发现问题就用清楚的话让 Claude Code 修改。

我不是老板，只是 HR / Sales / 行政，适合吗？

适合。很多重复、耗时的工作，正好是你最了解，也最能用小工具解决的。课程会按你的岗位选择练习场景。
